# Просмотр истории

Сотруднику без роли аудитора история чужой заявки недоступна. Аудитор может читать историю любой заявки своего подразделения. Для чужого подразделения доступ закрыт всем.

### Примеры
Аудитор открывает историю чужой заявки своего подразделения и получает историю. Сотрудник без роли аудитора при тех же условиях видит отказ.
