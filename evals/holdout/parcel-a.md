# Выдача посылки

Посылка поступает в пункт, система фиксирует момент поступления в UTC. Код выдачи действует 48 часов с момента поступления. Начиная с момента истечения срока код отклоняется.

### Выдача
Сотрудник вводит код. Для действующего кода система разрешает выдачу, для истёкшего показывает отказ.
